# krilly HAT (Pi 5 用の中継基板、#140)

ブレッドボードとジャンパ線で組んでいた配線 ([`docs/hardware/wiring.md`](../../docs/hardware/wiring.md)) を、
Raspberry Pi 5 に直接載せる 2 層基板にしたもの。設計は EasyEDA Pro 3.2 (API で操作)、製造は JLCPCB、
手付け部品は LCSC。**2026-10-11 発注済み (v1)。**

## ファイル

| ファイル | 中身 |
|---|---|
| `krilly-hat.epro2` | EasyEDA Pro のプロジェクト (回路図 + PCB)。EasyEDA の「ファイル → 開く」で読める |
| `fab/krilly-hat_Gerber.zip` | 製造データ (EasyEDA から書き出し)。JLCPCB にそのまま上げる |
| `fab/krilly-hat_BOM_JLCPCB.csv` | JLCPCB に実装させるチップ部品 5 個だけの BOM |
| `fab/krilly-hat_CPL_JLCPCB.csv` | 同じ 5 個の実装位置と向き |
| `fab/krilly-hat_LCSC_order.csv` | 手付け部品の LCSC 注文リスト (BOM Tool にそのまま上げられる) |

## 基板の形

- **65 × 56 mm、右下 (x ≥ 44, y ≥ 31 mm) を切り落とした L 字**。座標は Pi 5 の機械図と同じで、
  原点は 40 ピンヘッダ側の左上、y は下向き。切り落とした所に Pi のカメラコネクタ (CAM/DISP 0・1) がある。
  - カメラコネクタの位置は実測: ヘッダの縁からコネクタ手前まで 32 mm、右下の穴の中心から CAM1 の遠い側まで 14 mm。
  - カメラのケーブルは **HAT の上** を通す (真上に立ち上がって電源ボタン側へ)。左下の J3 とその上は背が高いので避ける。
- 取付穴は 3 つ (3.5, 3.5) / (61.5, 3.5) / (3.5, 52.5)、φ2.75 の NPTH。右下の穴は切り欠きの中なので使わない。
- Pi の電源ボタンは横から押すタイプなので、上に基板があっても押せる (切り欠き不要)。
- スペーサは M2.5 × **約 11 mm** の見込み (Pi のヘッダ台座 約 2.5 mm + メスヘッダ 8.5 mm)。**実物で測ってから選ぶ。**

| J1 | 2×20 メス 8.5 mm (PM254-2-20-Z-8.5) | C2897421 | (32.5, 3.5) | **裏面に実装** (下記) |
| J2 / J3 / J4 | ボックスヘッダ 2×5 | C5665 | 上 / 左下 / 右端 | L6470 の CN4 と同じピン配置。シルク M0 / M1 / M2 |

| J6 / J7 / J8 | XH 2P (VS 出力) | C161869 | 各ボックスヘッダの横 | L6470 の CN1 (ねじ端子) へ。1 番 = + |
| J9 | XH 2P (5V 入力) | C161869 | 左下 | X-UPS1 の 5V → J1 ピン 2・4 |
| SW1 | トグル (CAX-MTS102C3、5 A) | C55159897 | 左上 | 非常停止。VS を直接切る。レバーは左 (Pi の電源ボタン側) に出る |
| SW2 | タクト 6×6 | C5213765 | 左 | 開始ボタン (GPIO17)。180° 回して BTN 側を内側に |
| BZ1 | 電磁ブザー 9 mm 5V (TMB09A05) | C49246939 | J2 の下 | 1 番 = +5V。シルクの `+` に本体の + を合わせる |
| Q1 / R1 / R2 / D1 | SS8050 / 1 kΩ / 10 kΩ / 1N4148W | C2150 / C17513 / C17414 / C81598 | BZ1 の下 | ブザー駆動。**JLCPCB 実装 (Basic Part)** |
| J10 / J11 | 1×4 メス 8.5 mm | C3012026 | 中央 | BNO055 (AE-BNO055-BO) を載せる。向きは自由 (gyro z しか使わない) |
| JP1 / JP2 / JP3 | 1×2 ピン + ジャンパ | C492401 / C5305 | 中央下 | L6470 の #STBY / #BUSY / FLAG を GPIO22 / 23 / 24 へ。**出荷時は外す** |
| R3 | 10 kΩ | C17414 | JP の右 | GPIO22 側のプルアップ。**JLCPCB 実装** |
| J12 | 1×5 ピン | C492404 | 中央下 | SPI の観測用 (MOSI, MISO, SCLK, CE0, GND) |

ネットの一覧は `krilly-hat.epro2` の回路図が正。回路図から出したネットリストを手元の表と 94 ピンすべて突き合わせてある。
L6470 のチェインは J2 (MOSI → SDO0) → J3 (SDO0 → SDO1) → J4 (SDO1 → MISO) の順なので、
**どのケーブルをどの L6470 に挿すかでデバイス番号が決まる** (J2 = index 0 = M0)。

## 配線

- 電源 3 本は手で経路を決めた: **+5V** (J9 → J1 ピン 2・4) 表面 1.5 mm、**+12V** (J5 → SW1) と **VS** (SW1 → J6・J8・J7) 裏面 1.2 mm。
  - +5V と VS は XH コネクタに **真上から** 入れる。フットプリント内の Slot Region を斜めに横切ると DRC エラー。
- 残りは EasyEDA の GUI の自動配線 (Route → Auto Route、既存の配線は Keep): 線 361 本、ビア 24 個、100 %。信号は 0.254 mm。
- GND ベタを表裏両面 (孤立部分は削除)。**DRC エラー 0 件** (2026-10-11)。

## 組み立ての注意

1. **J1 は裏面から差して、表面ではんだ付けする。** フットプリントは表面に置いたまま (EasyEDA で裏面に移すと
   ピン配置が鏡像になり、3.3V と 5V が入れ替わる)。シルクに `J1=BOTTOM SIDE`、裏面にも注記あり。
   J1 の CPL は JLCPCB に渡していないので、製造には影響しない。
2. **J1 を最初に付ける。** J2 のボックスヘッダとの間が約 2.3 mm しかない。
3. BZ1 は本体の `+` をシルクの `+` (J2 側の左) に合わせる。データシートの外形図には極性の記載がない。
4. JP1〜JP3 は最初はジャンパを挿さない (今のソフトは #STBY / #BUSY / FLAG を使っていない)。

## 経緯と判断

- 当初 65 × 35 mm で考えたが、部品が詰まりすぎたので 65 × 56 mm にしてカメラコネクタの角だけ落とした。
- はんだジャンパ (0 Ω DNP) は位置的に扱いにくいので、ピンヘッダ + ジャンパに変えた。
- 非常停止は 0.5 A の SS-12D00G3 をやめ、5 A のトグルにした (VS はモータ 3 個分の電流が流れる)。
- ボックスヘッダはケーブルが互いに干渉しないよう、上 (J2)・下 (J3)・右 (J4) の 3 方向に向けた。
- EasyEDA 3.2 には自動配線の API がない (`autoRouting` は v4.1.66 から)。自前のグリッド配線器も試したが、
  GUI の自動配線の方が速くきれいだったので、そちらを使った。
- API の `rebuildCopperRegion()` は失敗し、そのあと EasyEDA が進捗 60 % のまま固まった。ベタの塗り直しは GUI の Shift+B で行う。
