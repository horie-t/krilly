### モータの仕様 (SS2421-5041、メーカーのカタログ p.44)

| 項目 | 値 |
|---|---|
| 形式 | □42 mm 薄型、1.8°/ステップ、**バイポーラ・リード線タイプ** (片軸) |
| 定格電流 | **1 A/相** |
| 巻線抵抗 | **3.5 Ω/相** |
| 巻線インダクタンス | 1.2 mH/相 |
| ホールディングトルク | 0.083 N·m 以上 (2 相励磁) |
| ロータイナーシャ / 質量 / モータ長 | 0.015×10⁻⁴ kg·m² / 0.07 kg / 11.6 mm |
| リード線 | **4 本、コネクタなし** (UL1007 AWG26、300 mm 以上)。A 相 = 橙・青、B 相 = 赤・黄 |
| カタログの特性図の条件 | 定電流駆動、DC 24 V、1 A/相、フルステップ |

L6470 は電圧で駆動するので、止まっているときの電流は `VS × KVAL / 256 ÷ 3.5 Ω` で見積もれる
(逆起電力とインダクタンスは無視、ピーク値)。今の設定 (VS 12 V):

| | KVAL | 巻線にかかる電圧 | 電流 (ピーク) |
|---|---|---|---|
| 走行 | 0x40 | 3.0 V | **約 0.86 A** (定格 1 A の内側) |
| 保持 | 0x20 | 1.5 V | 約 0.43 A |

12V 側は 3 台とも走行の KVAL で止まっている場合で、巻線の損失が 1 台あたり約 2.6 W、合計 7.8 W
(12 V で約 0.65 A + ドライバの損失)。X-UPS1 の 12 V / 3 A の内側に収まる。基板の 12 V の配線は
**3 台分で 1〜2 A** を見込めばよい。

## 3. L6470 ×3 (SPI0 デイジーチェーン)

SPI mode 3 (CPOL=1 / CPHA=1)、MSB first、5 MHz、CS は 1 本 (CE0)。

```
Pi MOSI ─▶ #0 SDI   #0 SDO ─▶ #1 SDI   #1 SDO ─▶ #2 SDI   #2 SDO ─▶ Pi MISO
Pi SCLK ─▶ #0/#1/#2 CK (共有)          Pi CE0 ─▶ #0/#1/#2 CS (共有)
```

MOSI・MISO と、L6470 どうしの SDO → SDI はジャンパ線で直結。CK と CS は左のブレッドボードの列で
3 台に分けている (§5)。

| L6470 | モータ / 車輪 | 位置 (機体座標) |
|---|---|---|
| #0 (MOSI に最も近い) | M0 / W0 | 前 (スポーク角 0°)。ほぼ横方向だけに駆動する車輪 |
| #1 | M1 / W1 | 左後ろ (120°) |
| #2 (MISO に最も近い) | M2 / W2 | 右後ろ (240°) |

| L6470 のピン | 今の扱い | 要確認 |
|---|---|---|
| VS (モータ電源) | X-UPS1 12V → **非常停止のスライドスイッチ** → 左のボードの 12V の列 → 3 台へ | 線の太さ |
| VDD / EXT-VDD | JP1 で内部 3V レギュレータ。EXT-VDD は未接続 (Pi の 3.3V とはつないでいない) | — |
| GND (電源側・ロジック側) | 電源側 GND ×3 は左のボードの GND の列 (X-UPS1 の GND と同じ列)、ロジック側 GND ×3 は「L6470 GND」の列。2 つの列はジャンパでつなぎ、さらに Pi のピン 9 へ | — |
| STBY/RESET | 未接続 (ソフトでも使っていない) | モジュール上でプルアップされているか (基板で引き出すなら) |
| BUSY / FLAG | 未接続 (状態は SPI の GetStatus で読む) | — |
| STCK | 未接続 (速度は SPI の Run で指令) | — |
| モータ出力 A+/A−/B+/B− | 各モータのリード線 4 本を **AE-L6470 の端子台にねじ止め** (途中にコネクタなし) | — |

### BNO055 (AE-BNO055-BO、[秋月の説明書](https://akizukidenshi.com/goodsaffix/AE-BNO055-BO_20220413.pdf))

| ピン | 名称 | つながる先 |
|---|---|---|
| 1 | VIN (3.3V/5.0V) | Pi ピン 1 (3.3V) |
| 2 | GND | Pi ピン 9 (左のボードの GND) |
| 3 | SDA/T | Pi ピン 3 |
| 4 | SCL/R | Pi ピン 5 |
| 5 | RESET (L でリセット) | 未接続 |
| 6 | INT (2.8V 出力) | 未接続 |
| 7 | GND | 未接続 |
| 8 | VOUT (2.8V 出力) | 未接続 |

- 出荷時のまま (J4・J5 接続 = I2C モード、J1 未接続 = アドレス 0x28)
- モジュール上にレギュレータ (2.8V) とレベル変換 (FXMA2102) があり、I/O は VIN の電位になる。
  **VIN は 3.3V にすること** (5V にすると SDA/SCL が 5V になる、setup-pi5 §3)
- ピンは 1×4 の細ピンヘッダ 2 列、列の間隔 7.62 mm・ピッチ 2.54 mm、基板 18 × 11 mm

## 4. 電源

```
X-UPS1 ─ 5V (XH2.54) ──▶ Pi ピン 2 (5V) / ピン 6 (GND) ──▶ Pi 5 (GPIO / カメラ / BNO055 3.3V / ボタン・ブザー)
       ├ 12V (VH3.96) ──▶ 非常停止のスライドスイッチ (右のボード) ──▶ 左のボードの 12V の列 ──▶ L6470 ×3 VS ──▶ モータ ×3
       └ GND ──▶ 左のボードの GND の列 ──(ジャンパ)── L6470 ロジック GND の列 ──▶ Pi ピン 9
```

- Pi の USB-C は使わない (X-UPS1 の 5V と二重給電になる、setup-pi5 §8)
- X-UPS1 の出力コネクタ: **12V は VH3.96、5V は XH2.54**。LBAT / PLD は Pi につないでいない
- 12V は安定化されているので、電圧を測っても残量は分からない (venue-checklist §1)
- 起動・停止の手順は venue-checklist §6

12V 側の GND は左のボードで Pi の GND (ピン 9) とつながっている。X-UPS1 の中で 5V 側と共通かどうかに
関わらず、機体の GND は 1 つにまとまっている。


## 5. ブレッドボードの配線 (2026-10-10 の手書きの配線図から)

小型のブレッドボード 2 枚。「列」はブレッドボードでつながっている穴の並び。

**左のボード** (電源・SPI・BNO055):

| 列 | 挿してあるもの |
|---|---|
| 12V | スライドスイッチを通った X-UPS1 の 12V、L6470 ×3 の VS |
| GND | X-UPS1 の GND、L6470 ×3 の電源側 GND、「L6470 GND」の列へのジャンパ |
| L6470 GND | L6470 ×3 のロジック側 GND、Pi の GND の列へのジャンパ |
| logic CLK | L6470 ×3 の CK、Pi の SCLK (ピン 23) |
| (空き 2 列) | — |
| Pi 3.3V | Pi ピン 1、BNO055 ① VIN |
| Pi GND | Pi ピン 9、BNO055 ② GND、L6470 GND の列からのジャンパ |
| Pi SDA | Pi ピン 3、BNO055 ③ SDA |
| Pi SCL | Pi ピン 5、BNO055 ④ SCL |
| L6470 CS | L6470 ×3 の CS、Pi の CE0 (ピン 24) |

BNO055 の ⑤〜⑧ の列には何もつないでいない。

**右のボード** (ボタン・ブザー・非常停止):

| 列 | 挿してあるもの |
|---|---|
| タクトスイッチの上側 | Pi の GPIO17 (ピン 11) |
| タクトスイッチの下側 | GND の列へのジャンパ |
| GND | Pi の GND (ピン 20)、ブザーの一方のピン |
| ブザーのもう一方 | Pi の GPIO18 (ピン 12) |
| スライドスイッチの真ん中 | 左のボードの 12V の列への長い線 |
| スライドスイッチの端 | X-UPS1 の 12V |

非常停止のスライドスイッチは右のボードにあるが、ボタンやブザーとは電気的につながっていない。

## 6. これまでの配線トラブル (基板の要件に変える)

| 起きたこと | 原因 | 基板での対策の候補 |
|---|---|---|
| L6470 の STATUS が 0x0000 のまま (2026-07) | 旧 Pi の GPIO8/9 が GND に短絡 + ケーブルの接触不良・ずれ | ロック付きのコネクタ。SPI の信号を確かめるテストポイント |
| ボタンが反応しない (#79) | GND をピン 20 のつもりでピン 22 (GPIO25) に挿した | ヘッダは基板ごと挿す (ピン単位で挿さない) |
| 走行中に 3 台とも `NO_SPI` (試走会 2026-09-26) | SPI のコネクタの接触不良 (CK と CS はブレッドボードの接点も通る) | 同上。L6470 との間は基板上の配線かロック付きコネクタ |
| (要因の候補) | 右のボードの GND がピン 20 = SPI のピン 19/21 の隣で、挿し抜きのたびに SPI を押す | GND は基板上でまとめる |
| SPI が途切れている間、L6470 は最後の指令のまま動く | 構造上の性質 | (ソフト側の課題。基板では BUSY/FLAG を GPIO に引く余地を残す?) |
