# 全日本マイクロマウス大会の迷路 (書き起こし)

大会記録集の図から `scripts/maze_from_image.py` で自動抽出したもの (issue #84)。
2010〜2024 年、**31 面**すべて異なる迷路。

```bash
# 再抽出 (図を追加したとき)
python -m scripts.maze_from_image <画像>... --out-dir mazes/contest

# 通しセッションを回す
python -m scripts.maze_sim --maze mazes/contest/*.txt
```

## なぜ本物が要るのか (生成迷路との差を実測した)

**壁の密度を合わせても、生成した迷路は本物の 4 分の 1 の難しさしかない。**
31 面ずつ比べた中央値:

| | 内壁 | 解 | 探索 | 最速ラン | 走行回数 |
|---|---|---|---|---|---|
| **実際の大会迷路** | **214** | **59 歩** | **90 手** | **77s** | **3 回** |
| 生成 `loop_ratio=0.10` | 193 | 16 歩 | 21 手 | 25s | 5 回 |
| 生成 `loop_ratio=0.35` | 147 | 14 歩 | 17 手 | 19s | 5 回 |
| 生成 `loop_ratio=0.00` | 225 | 82 歩 | 82 手 | 91s | 2 回 |

内壁 214 枚の本物の解が 59 歩なのに対し、内壁 193 枚の生成迷路は 16 歩。
**難しさを作っているのは壁の枚数ではなく配置**で、そこは乱数では再現できない。

一方**局所の指標は生成迷路とよく一致する** (X 補正なしのセル 27% 対 28%、
Y 28% 対 30%、四辺とも壁なしのセル 4 個対 5 個)。つまり:

- カメラ判定・1 セルの制御 (#85) は生成迷路でもある程度代表できる
- 探索・経路計画・10 分予算は**本物でしか試せない**

## 分かったこと

- **2 面は最速ランを 1 本も走れない** (2011 エキスパート決勝は探索 236 手、
  2017 エキスパート決勝は 121 歩の解)。10 分の予算はぎりぎり
- 走行 5 回を消化できたのは 31 面中 **1 面だけ** (2016 フレッシュマン予選)
- 探索の手数は 32〜236 手、解は 24〜121 歩と幅が大きい

## 読み取りの検証

`scripts/maze_from_image.py` は迷路として成立する読み取りしか採らない
(外周が閉じている / スタートからゴールへ到達可能 / 内壁が連結の上限以下)。
そのうえで個別に確かめたもの:

| 迷路 | 確認したこと |
|---|---|
| `2013_japan_exp_q` | 図の下部に**公式解「西回り 52歩29折、54歩29折 南回り 52歩25折、54歩23折」**が記載されている。抽出した迷路の最短経路が **52 歩 29 折**、折れ最小が **52 歩 25 折**で一致 |
| `2013_japan_exp_q` | 裸の柱が 27 本あるのは読み落としではない (柱 (1,9) を 10 倍に拡大し、四方が点線のみであることを確認) |
| `2010_japan_freash_fin` | 裸の柱 2 本目 (11,3) を同様に拡大して確認 |
| `2020_japan` | 四方を壁で囲まれたセル (11,6) を拡大して確認。**囲まれたセルは大会迷路に実在する** |

**「裸の柱はゴール中央の 1 本だけ」は 31 面中 28 面で成り立つが、規則ではない。**
上の 2 面が反例で、抽出ツールもこれを誤りとして弾かず「要確認」に回すだけにしてある。

ゴールは全面が中央 2x2。図によっては `G` が 1 個しか書かれていないので、
1 セルだけ検出したときは中央 2x2 に補正している (2013 年の公式解との一致で裏を取った)。
