# 白・黄の壁上面の判定用フレーム (#125)

すべて同じ条件で撮った: **黒い競技用床 (自宅)・`--ev -2`・960×720**。機体の上面は
つや消しの緑のフェルトで覆ってあり、カメラには H 98 / S 255 で写る。撮ったのは 2026-09-23 で、
場所は同じ 1 セル (壁は柱に差し込む)。各セットは `wall_detect --measure 5 --save-prefix` の
5 フレーム (`_01`〜`_05`)。

| セット | 壁 | 機体 | 備考 |
|---|---|---|---|
| `on_4w` | 赤 4 枚 | 中央 | フェルトを調整する**前**、支柱は金属のまま。BACK の既定 ROI の 22 % がフェルト |
| `on_0w` | なし (柱だけ) | 中央 | 同上 |
| `on_4w-2` | 赤 4 枚 | 中央 | フェルトを調整し (BACK 既定 ROI の 7 %)、支柱を緑のテープで覆った後 |
| `wy_a` | front/right = 白、back/left = 黄 | 中央 | |
| `wy_b` | front/right = 黄、back/left = 白 | 中央 | |
| `on_0w-2` | なし (柱だけ) | 中央 | |
| `on_0w-2s` | なし (柱だけ) | 右へ ~15 mm | 床の光沢が RIGHT の探索範囲に入る。**明るさだけの判定はここで 0.245 と読んだ** |
| `wy_a_s` | front/right = 白の 2 枚だけ | 右へ ~13 mm | 白い帯と床の光沢が同じ ROI に並ぶ |

ゲインは 2.35〜3.25 (白い壁があると AE が絞って下がる)。床の光沢は画像の右側
(天井灯の映り込み) に出て、その彩度は `on_0w` で S 46〜57、`on_0w-2` / `on_0w-2s` で S 11〜30
だった — 同じ場所・同じゲインで動いたので、白と彩度で分けることはできない。

`tests/data/white_tops/` にはこのうち 5 枚 (`wy_a` / `wy_b` / `on_0w-2s` / `on_4w-2` / `wy_a_s`
の各 `_03`) を回帰テスト用に置いてある。
